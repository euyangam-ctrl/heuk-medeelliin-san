# ХЭҮК мэдээллийн сан

Хүний эрхийн Үндэсний Комиссын санал, зөвлөмж, гишүүний шаардлага, гишүүний зөвлөмж, хууль тогтоомжийн төсөлд өгсөн санал, дүн шинжилгээ, судалгаа болон илтгэлийн саналын тогтоолд тусгагдсан байдлыг нэгтгэсэн вэб сан. Сан нь 2001 оноос хойших 1 949 баримт, 25 илтгэлд өгсөн 616 санал, 620 PDF эх хувийг агуулна.

Сайтын хаяг: https://euyangam-ctrl.github.io/heuk-medeelliin-san/

## Бүтэц

1. index.html нь сайтын үндсэн файл. Хайлт, хяналтын самбар, баримтын жагсаалт, PDF уншигч, админы засварын хэсгийг агуулна.
2. data.json нь бүх баримт, илтгэл, тохиргооны мэдээлэл. data.js нь ижил мэдээллийг компьютер дээрээс шууд нээхэд зориулсан хэлбэрээр агуулна. Админ хадгалах бүрд хоёулаа хамт шинэчлэгдэнэ.
3. pdf хавтсанд баримт бүрийн PDF эх хувь баримтын дугаараар нэрлэгдэж хадгалагдана. Жишээ нь pdf/zov-2026-0046.pdf.
4. admins.json нь админ хэрэглэгчдийн шифрлэгдсэн бүртгэл. Анхны тохиргоо хийхэд үүснэ. Гараар засахгүй.
5. lib хавтсанд PDF уншигч (pdf.js 3.11.174, Apache 2.0 лиценз) болон Excel үүсгэгч (SheetJS 0.18.5, Apache 2.0 лиценз) байрлана. Ингэснээр гадны CDN хаагдсан сүлжээнд болон интернэтгүй үед ч PDF нээгдэж, Excel татагдана.
6. .nojekyll файл нь GitHub Pages-ийг файлуудыг өөрчлөлтгүй нийтлэхийг заана. Энэ файлыг устгахгүй.

## Сайтыг нийтлэх

1. Репогийн Settings цэсийг нээж, зүүн талын жагсаалтаас Pages хэсгийг сонгоно.
2. Build and deployment хэсгийн Source талбарт Deploy from a branch сонголтыг сонгоно.
3. Branch талбарт main салбар, / (root) хавтсыг сонгож Save товчийг дарна.
4. 1-3 минутын дараа сайт дээрх хаягаар нээгдэнэ.

## Офлайн ашиглах

Мэдээллийн санг бүх PDF-ийн хамт компьютер дээрээ татаж авбал интернэтгүй үед ч хайлт хийх, хяналтын самбар үзэх, PDF нээх, Excel татах боломжтой.

1. Сайтын хяналтын самбарын доод хэсэгт байрлах Офлайн ашиглахаар татах холбоосыг дарж, ZIP татах товчийг дарна. Мөн https://github.com/euyangam-ctrl/heuk-medeelliin-san/archive/refs/heads/main.zip хаягаар шууд татаж болно.
2. Татсан ZIP файл дээр хулганы баруун товчийг дарж Extract All (Бүгдийг задлах) сонголтоор задлана. ZIP файлын дотроос шууд нээвэл мэдээлэл ачаалагдахгүй.
3. Задалсан хавтасны index.html файлыг Chrome, Edge эсвэл Firefox хөтчөөр нээнэ. PDF нь pdf хавтаснаас хөтчийн өөрийн уншигчаар нээгдэнэ.

Татаж авсан хувилбар тухайн өдрийн мэдээллийг агуулна. Шинэ бүртгэлийг авахын тулд дахин татна. Татаж авсан хувилбараас мэдээлэл засах боломжгүй, засварыг онлайн сайтаар хийнэ.

## Хэрэглэгчид

Сайтыг нээсэн хэн бүхэн мэдээллийг үзэх, хайх, хяналтын самбар ашиглах, PDF нээх, Excel файл татах боломжтой. Мэдээлэл нэмэх, засах, устгах эрх зөвхөн ерөнхий админ бүртгэсэн админд олгогдоно.

## Админ нэвтрэх

Админ нэр, нууц үгээр нэвтэрнэ. Админд GitHub бүртгэл шаардлагагүй. Нэвтрэх цонх хяналтын самбарын доод хэсэг болон зүүн цэсний доод хэсэгт байрлах Админ нэвтрэх холбоосоор нээгдэнэ. Хаягийн ард ?admin гэж нэмж нээсэн ч нэвтрэх цонх гарна.

Админ хоёр төрлийн эрхтэй.

1. Ерөнхий админ нь мэдээлэл нэмж засахаас гадна админ нэмэх, хасах, GitHub-ийн түлхүүр солих эрхтэй.
2. Админ нь баримт бүртгэх, PDF хавсаргах, мэдээлэл засах, өөрийн нууц үгийг солих эрхтэй.

### Анхны тохиргоо

Анхны тохиргоог ерөнхий админ нэг удаа хийнэ.

1. https://github.com/settings/personal-access-tokens/new хуудсыг нээнэ.
2. Token name талбарт нэр өгч, Expiration талбарт хүчинтэй хугацааг сонгоно.
3. Repository access хэсэгт Only select repositories сонголтыг сонгож, heuk-medeelliin-san репог нэмнэ.
4. Permissions хэсгийн Repository permissions доторх Contents зүйлд Read and write эрх олгоно.
5. Generate token товчийг дарж, гарсан түлхүүрийг хуулж авна.
6. Сайтын Админ нэвтрэх холбоосыг дарахад Админы бүртгэл үүсгэх цонх гарна. Өөрийн нэр, дор хаяж 10 тэмдэгттэй нууц үг, хуулж авсан түлхүүрийг оруулж Бүртгэл үүсгэх товчийг дарна.

Үүний дараа түлхүүр таны нууц үгээр шифрлэгдэж admins.json файлд хадгалагдах тул түүнийг дахин оруулах шаардлагагүй.

### Админ нэмэх, хасах

1. Ерөнхий админ нэвтэрч, Удирдлага цэсний Админ хэрэглэгчид хэсгийг нээнэ.
2. Админ нэмэх товчийг дарж нэр, нууц үг, эрхийг сонгоно.
3. Нэр, нууц үгийг тухайн хүнд биечлэн эсвэл найдвартай сувгаар дамжуулна. Нэвтрэхдээ нэрийг бүртгэсэнтэй адил оруулах ба том, жижиг үсэг хамаарахгүй.
4. Админ нэвтэрсний дараа Удирдлага цэсний Нэвтрэлт хэсгээс нууц үгээ өөрөө сольно.
5. Админыг хасахад тухайн хүн цаашид нэвтрэх боломжгүй болно. Эрхийг бүрэн цуцлахыг хүсвэл доорх Түлхүүр солих журмыг Бусад админы нэвтрэх эрхийг цуцлах сонголттойгоор хийнэ.

### Түлхүүр солих

GitHub-ийн түлхүүрийн хугацаа дуусахад сайт хадгалж чадахгүй болж, ерөнхий админ нэвтрэх үед шинэ түлхүүр оруулах цонх гарна. Түлхүүрийг хугацаанаас нь өмнө солих бол Админ хэрэглэгчид хэсгийн GitHub түлхүүр солих товчийг ашиглана.

1. Дээрх анхны тохиргооны 1-5 дугаар алхмаар шинэ түлхүүр үүсгэнэ.
2. Шинэ түлхүүрийг оруулж Хадгалах товчийг дарна. Бусад админы нэр, нууц үг өөрчлөгдөхгүй.
3. Админыг хассаны дараа эрхийг бүрэн цуцлах бол https://github.com/settings/personal-access-tokens хуудаснаас хуучин түлхүүрийг хүчингүй болгож, шинэ түлхүүрийг Бусад админы нэвтрэх эрхийг цуцлах сонголттойгоор оруулна. Ингэхэд зөвхөн таны бүртгэл үлдэх тул бусад админыг шинэ нууц үгээр дахин нэмнэ.

### Бүх нууц үг мартагдсан үед

Ерөнхий админ нэвтрэх цонхны GitHub түлхүүрээр нэвтрэх холбоосоор шинэ түлхүүр ашиглан нэвтэрч, Удирдлага цэсний Админ хэрэглэгчид хэсэгт Бүртгэлийг шинээр үүсгэх товчийг дарна. Хуучин бүртгэл бүхэлдээ солигдож, зөвхөн таны бүртгэл үлдэнэ.

## Өөрчлөлт хадгалагдах журам

1. Засвар хийснээс хойш 10 секунд өнгөрөхөд өөрчлөлт репод автоматаар хадгалагдана. Хадгалаагүй өөрчлөлт байх үед Одоо хадгалах товчоор шууд хадгалж болно.
2. Хадгалсан өөрчлөлт бүр репод тусдаа commit болж бүртгэгдэх тул хэн, хэзээ, юуг өөрчилснийг Commits хуудаснаас харж, шаардлагатай бол сэргээж болно.
3. Нийтийн хуудсанд өөрчлөлт 1-2 минутын дотор гарна.
4. Хоёр админ нэг зэрэг засварласан тохиолдолд сайт анхааруулга өгч, өөрийн хувилбараар хадгалах эсвэл сүүлийн хувилбарыг ачаалах сонголт санал болгоно.
5. Баримтыг устгахад түүний PDF файл репоос хамт устгагдана.

## Анхаарах зүйл

1. GitHub Pages-ийн үнэгүй хувилбар нь нээлттэй репо шаарддаг. Иймд data.json болон pdf хавтсанд байгаа бүх файлыг интернэтээр хэн ч татаж авах боломжтой. Хувь хүний нууцад хамаарах мэдээлэл агуулсан PDF-ийг оруулахгүй байх нь зүйтэй.
2. admins.json файл нээлттэй репод байрлах ч админы нэр, GitHub-ийн түлхүүр нууц үгээр шифрлэгдсэн тул нууц үггүйгээр уншигдахгүй. Шифрийг таахад нууц үгийн бат бөх байдал шийдвэрлэх ач холбогдолтой тул дор хаяж 10 тэмдэгттэй, таахад хэцүү нууц үг сонгоно. Үүнийг хангах үүднээс сайт 10 тэмдэгтээс богино нууц үгийг хүлээн авахгүй.
3. Энэ төхөөрөмж дээр сануулах сонголтыг зөвхөн өөрийн компьютер дээр ашиглана. Олон хүний хэрэглэдэг компьютер дээр ажлаа дуусгаад Гарах товчийг дарна.
4. GitHub-ийн түлхүүрийг бусдад дамжуулахгүй. Түлхүүр алдагдсан эсвэл шаардлагагүй болсон бол https://github.com/settings/personal-access-tokens хуудаснаас хүчингүй болгоно.
5. GitHub Pages сайтын нийт хэмжээ 1 ГБ-аас хэтрэхгүй байх шаардлагатай. Одоогийн хэмжээ 760 МБ орчим. Нэг файлын дээд хэмжээ 100 МБ.
6. Claude дээрх анхны хувилбар болон энэ сайт хоорондоо автоматаар холбогдохгүй. Цаашид мэдээллийг энэ сайтаар дамжуулан шинэчлэхийг зөвлөж байна.
